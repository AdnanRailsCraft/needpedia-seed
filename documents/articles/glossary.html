NEEDPEDIA GLOSSARY

here are canonical. Report conflicts to Needpedia@gmail.com.

ADELE — AI assistant for volunteer coordination, working in the public

email system alongside the human Volunteer Coordinator. Named after a

librarian who resisted fascism.

BOTSKILL — A nexus post written primarily for Needpedia's AI

assistants rather than humans: instructions for specialized tasks

(e.g., onboarding developers, researching regulations efficiently).

Botskills are public — any curious human can read them — but they're

kept separate so the nexus stays uncluttered.

CHECKBACK DATE — A date on a task card indicating when the task should

be checked on for progress.

DEBATE TOKEN — A token hosting structured arguments for and against an

idea. Users rate each argument individually, revealing precisely what

people are concerned about.

ECO MODE / FULL MODE — Options for Florence and Lotte. Full mode uses

a more powerful AI; eco mode uses over 10x less energy.

FEDERATION — Needpedia's (experimental) ability to share wiki content

between separate Needpedia instances.

FEDIVERSE — The network of interconnected social platforms (Mastodon

and others). Needpedia's social media section has limited,

lightly-tested fediverse access.

FLORENCE — AI greeter for visitors who aren't logged in yet. Answers

questions and helps people decide whether to join. Named after a

librarian who resisted fascism.

GEOMAXXING — Using Needpedia's mapping feature to share and develop

ideas tied to physical locations ("spatial ideas").

GROUP ACCOUNT — An account operated by an organization or team rather

than an individual. Group accounts can post task cards.

HAVE/WANT — Profile sections listing goods or services you have or

want, enabling barter and mutual aid. Requires 2FA.

IDEA POST — A post proposing a solution or creation, attached to one

or more problem posts. Contains a description, related problems, and

objectives.

/IMPACT — The section crediting users' contributions to projects,

similar to how GitHub credits code contributions. Builds visible track

records and networks of trust.

KNOW AGENDA FOUNDATION — The foundation providing fiscal sponsorship

to Needpedia, enabling tax-deductible donations.

LAYER — A dedicated discussion space attached to a post. Common types:

expert layers (specialists evaluate an idea), lived-experience or

identity layers (e.g., women, disabled people, or people who've

experienced homelessness discuss an idea amongst themselves, then

share input publicly), and NVC layers (see NVC). Created via the

"Layer" button at a post's upper right.

LOL VOTE — A vote type for ideas that are funny rather than good,

preventing humor from inflating an idea's serious ranking.

LOTTE — The main AI assistant for logged-in users. Can find, create,

and edit wiki posts via API on a user's behalf, works in many

languages, and can explain site content — including in

age-appropriate ways. Named after a librarian who resisted fascism.

NEXUS — Needpedia's community resource hub at nexus.needpedia.org:

tiles linking to articles, media, tools, botskills, and (for

volunteers with the password) AI studios and file upload.

NOTE TOKEN — A token adding context, sources, or corrections directly

after any statement in a post.

NVC (NONVIOLENT COMMUNICATION) — A communication method built on

judgment-free observations, feelings, needs, and requests. NVC layers

expect all statements to follow NVC form, keeping controversial

discussions productive. Not censorship of positions — structure for

expressing them.

OBJECTIVE — A concrete, completable step listed inside an idea post.

When an objective is completed, followers of the post are notified.

PROBLEM POST — A post describing a problem, attached to a subject.

Ideas are posted under problems.

PUBLIC EMAIL SYSTEM — Needpedia's volunteer coordination inbox

(vc-email-five.vercel.app), readable by anyone in guest mode. Exists

primarily for coordination and situational awareness as the

organization scales; transparency is the trust bonus. For private or

anonymous matters, use Needpedia@gmail.com instead.

QUESTION TOKEN — A token asking for clarification on a specific word

or statement in a post.

SUBJECT POST — The broadest post type: any topic (a place, movement,

artwork, language, field). Problems are listed under subjects.

TASK CARD — A card describing work a group needs done, with skill tags

and a checkback date, findable via search.

TILE — A block on the nexus homepage linking to a resource.

TIME BANK — Needpedia's system for exchanging help using time credits

instead of money.

TOKEN — An icon dropped into a post's text (via the Edit button) at

the exact spot it concerns, (after any word or statement in user-generated text bodies). Types: Question, Note, Debate. See

each entry.

VC / VOLUNTEER COORDINATOR — The human coordinating Needpedia's

volunteers, reachable at VC@Needpedia.org (public system).

2FA — Two-factor authentication; required for the Have/Want feature.
